# چک‌لیست پیش از عمومی‌کردن مخزن

- [ ] تأیید حقوق کد و هندسه کشتی/یدک‌کش از همه صاحبان حقوق گرفته شده است.
- [ ] فایل LICENSE بر اساس مجوز تأییدشده ایجاد شده است.
- [ ] نام نویسندگان و وابستگی‌ها در CITATION.cff بررسی شده‌اند.
- [ ] نتایج مقاله با داده‌های ۲۳ اجرای ثبت‌شده تطبیق داده شده‌اند.
- [ ] روی سیستم مستقل، pip install، pytest و verify_repository موفق بوده‌اند.
- [ ] سطح دسترسی مخزن مناسب است (Private تا زمان موافقت همه نویسندگان).
- [ ] اطلاعات حساب، توکن و فایل محرمانه در commitها وجود ندارد.
- [ ] URL واقعی GitHub و DOI واقعی Zenodo در متن مقاله وارد شده‌اند.
- [ ] متن Data availability تنها فایل‌هایی را وعده می‌دهد که واقعاً عمومی شده‌اند.
