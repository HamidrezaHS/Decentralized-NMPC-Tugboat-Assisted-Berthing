# License approval required before public distribution

This package intentionally does **not** automatically grant an open-source license. Before making the repository public, obtain agreement from all copyright holders and check whether any geometry file, external dependency, data item, or institutional policy restricts redistribution.

If all authors approve use of a permissive software license such as MIT, copy the **reviewed** license text from `docs/templates/LICENSE_MIT_TEMPLATE.txt` to a root file named `LICENSE`, replace the placeholders, and commit that new file. Otherwise choose the license approved by your institution and coauthors.

Until then: maintain a private repository; do not claim that external users have a license to redistribute or modify the code. The underlying Python dependencies keep their own licenses regardless of your choice.
