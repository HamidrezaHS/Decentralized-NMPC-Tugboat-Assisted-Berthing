# Research software accompanying the manuscript

**Suggested GitHub tag:** `v1.0.0`

This release provides the decentralized ship-state NMPC implementation and archived numerical evidence accompanying the manuscript *Decentralized nonlinear model predictive control for cooperative tug-assisted ship berthing under varying environmental conditions*.

### Contents
- Coupled five-vessel ship/tug simulation and decentralized NMPC controller
- 16 direction-varying wind/current numerical runs, 6 regression runs, and one supplementary heading test
- Raw simulation configurations, metrics, trajectories and control decisions
- Reproducible plotting utilities, tests and citation metadata

### Limits
These are deterministic simulation results under stated assumptions, not an operational guarantee or a measured-data benchmark. Refer to the manuscript for model assumptions, terminal criteria and limitations.
